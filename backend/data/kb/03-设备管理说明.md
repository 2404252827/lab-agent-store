# 设备管理说明

## 设备包含哪些字段

| 字段 | 说明 |
| --- | --- |
| 所属实验室 | 设备必须从属于某个实验室 |
| 设备名称 | 例如「示波器」「3D 打印机」 |
| 说明 | 设备的文字描述 |
| 展示 | 设备图片地址 |
| 型号规格 | 例如「Tektronix TBS1102」 |
| 数量 | 该设备的数量，默认为 1 |
| 状态 | 0 表示维修，1 表示正常，默认为正常 |

## 设备与实验室的关系

每台设备都必须挂在某个实验室下面，不能独立存在。新建设备时如果指定的实验室不存在，会提示「实验室不存在，新增失败」。因此删除实验室之前，必须先删掉它下面的所有设备。

## 设备状态的含义

状态为 1 表示正常，状态为 0 表示维修中。在设备列表中可以直观看到哪些设备处于维修状态，安排实验前可以先确认设备是否可用。

## 设备名称不能重复

同一个实验室内部，设备名称不能重复。重复新增会提示「实验室已经存在此种设备」。如果是在修改时改名撞上了同实验室的其他设备，提示「实验室已存在此种设备，更新失败」。

需要注意，不同实验室可以有同名的设备，例如两个实验室各有一台「示波器」，这是允许的。

## 新增、修改和删除设备

新增、修改、删除设备都需要管理员权限。删除设备本身没有额外的前置条件，但如果该设备所属的实验室之后要被删除，需要先删除设备。

## 查询设备

登录用户可以查看设备列表，支持分页、关键字模糊匹配设备名称，也可以按实验室编号筛选，查看某个实验室下的全部设备。
