# 实验室信息说明

## 实验室包含哪些字段

| 字段 | 说明 |
| --- | --- |
| 名称 | 实验室名称，全局唯一，不能与已有实验室重名 |
| 简介 | 实验室的文字介绍 |
| 封面 | 实验室的展示图片地址 |
| 位置 | 实验室所在的具体位置 |
| 容量 | 可容纳人数，默认为 0 |
| 开放时间 | 每天允许开始预约的最早时间，格式 HH:MM |
| 关闭时间 | 每天允许预约的最晚结束时间，格式 HH:MM |
| 状态 | 0 表示关闭，1 表示开放，默认为开放 |

## 实验室状态的含义

状态为 1 表示开放，可以正常预约。状态为 0 表示已关闭，此时该实验室不能被预约，提交预约会提示「实验室已关闭，暂不可预约」。

关闭实验室不会影响已经存在的预约记录，只是不再接受新的预约。

## 开放时间与关闭时间的限制

关闭时间必须晚于开放时间，否则新增或修改时会提示「结束时间需要晚于开放时间」。时间按 HH:MM 字符串比较，需要补零，例如写 08:00 而不是 8:00。

## 新增和修改实验室

新增实验室需要管理员权限。名称重复时提示「实验室已存在，请勿重复添加」。修改时如果把名称改成其他实验室已占用的名称，会提示「实验室名称已被其他实验室占用」。

## 删除实验室的限制

删除实验室需要管理员权限，并且有两个前置条件，必须按顺序处理：

1. 该实验室下面不能还有设备，否则提示「删除实验室失败，请先删除实验室设备」。
2. 该实验室不能还有任何预约记录，否则提示「删除实验室失败，请先处理该实验室的预约记录」。

之所以限制预约记录，是因为预约表通过外键指向实验室，直接删除会触发数据库外键约束错误。

## 查询实验室

所有登录用户都可以查看实验室列表，支持分页，也可以用关键字模糊匹配实验室名称。每页默认 10 条，最多 100 条。
