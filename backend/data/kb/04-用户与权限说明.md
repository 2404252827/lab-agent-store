# 用户与权限说明

## 用户角色

系统有两种角色：

| 角色值 | 名称 | 说明 |
| --- | --- | --- |
| admin | 管理员 | 拥有全部权限，可以管理实验室、设备和用户，并审核预约 |
| user | 普通用户 | 可以浏览实验室和设备、预约实验室、管理自己的信息 |

注册时不能注册为管理员，如果提交的角色是 admin，会提示「不能注册为管理员」。管理员账号只能由管理员在后台创建。

## 用户状态

状态为 1 表示正常，状态为 0 表示已禁用。被禁用的用户无法登录，登录时会提示「用户已被禁用」。用户列表默认不显示管理员账号。

## 注册与登录

注册需要提供账号，账号不能与已有账号重复，重复会提示「用户已存在」。昵称可以为空，为空时默认使用账号作为昵称。

登录使用账号加密码，账号不存在或密码错误统一提示「账号或密码错误」，不会提示具体是哪一项错误。登录成功后返回一个 JWT 令牌。

## 登录令牌的有效期

JWT 令牌默认有效期为 24 小时。前端在每次请求的请求头里带上 Authorization: Bearer 令牌。令牌过期或无效时接口返回 401，前端会提示「登录已失效，请重新登录」并跳转登录页。

## 修改密码

修改密码需要提供原密码，原密码错误会提示「原密码错误」。新密码经过 bcrypt 加密后存储，数据库中不保存明文密码。

## 权限速查表

| 操作 | 普通用户 | 管理员 |
| --- | --- | --- |
| 查看实验室列表 | 可以 | 可以 |
| 新增 / 修改 / 删除实验室 | 不可以 | 可以 |
| 查看设备列表 | 可以 | 可以 |
| 新增 / 修改 / 删除设备 | 不可以 | 可以 |
| 提交实验室预约 | 可以 | 可以 |
| 查看预约列表 | 只能看自己的 | 可以看全部 |
| 审核预约 | 不可以 | 可以 |
| 取消预约 | 只能取消自己的待审核预约 | 只能取消自己的待审核预约 |
| 查看用户列表 | 不可以 | 可以 |
